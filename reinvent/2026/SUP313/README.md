## SUP313 - Implementing an eval strategy while building AgentCore agents without a QA team
AWS re:Invent 2026

### Session Type
Interactive Session

### Abstract
Startups shipping AI can move fast for the same reason a car can. You trust the brakes. For agents, evals are those brakes. In this session, you build an agent locally with AgentCore and evaluate it as you go with Amazon CloudWatch Omni, without a QA team. Every change you make in your IDE is scored on sessions, responses, and tool calls, so you see right away whether your agent got better. When the scores hold, deploy the same agent to AWS and keep the same evals running on production traffic. Leave with an eval workflow a lean team runs solo, so you can keep your foot on the gas.
