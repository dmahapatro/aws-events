## API319 - Orchestrating AI agents with AWS Serverless services
AWS re:Invent 2026

### Session Type
Breakout Session

### Abstract
Production AI agents need orchestration that handles non-deterministic behavior, multi-hour workflows, human approvals, and multi-agent coordination. Learn how AWS Step Functions and AWS Lambda durable functions provide the reliability layer that agents demand. We cover patterns for durable execution, human-in-the-loop controls, event-driven agent communication, and the scale-to-zero economics that make serverless the natural home for agentic workloads.
