## SVS326 - Thinking agentic: What developers using Serverless need to know
AWS re:Invent 2026

### Session Type
Chalk Talk

### Abstract
You've been building event-driven, async systems for years. Agents are a new type of consumer in your existing architecture. In this chalk talk, we discuss what actually changes: reframing functions as tools with schema-first interfaces, managing agent state with storage and checkpoints, and handling non-deterministic failures from LLM calls. We walk through a practical path from "I have a serverless app" to "my app has agent capabilities," adding capabilities incrementally without rewriting what already works. Bring your architecture. We'll whiteboard where agents fit in what you've already built.
